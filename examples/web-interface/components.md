# Web interface — components

Detailed component breakdown applying the 12 principles to web UI.

## 1. Button

- **Purpose:** the most used interactive element; needs clear affordance.
- **Principles applied:**
  - **Squash and Stretch:** the button compresses on press (10–15%) and
    springs back on release.
  - **Anticipation:** a 100–150ms hover lift precedes the click.
  - **Staging:** the primary action is the most prominent element.
  - **Timing:** 150ms press feedback; 200ms for full press.
  - **Appeal:** consistent style, clear label, high contrast.

## 2. Card

- **Purpose:** groups related content.
- **Principles applied:**
  - **Staging:** the card with the primary action stands out.
  - **Follow Through:** sibling cards stagger reveal by 60–120ms.
  - **Timing:** 300ms slide in.

## 3. Modal

- **Purpose:** interruptive but focused content.
- **Principles applied:**
  - **Staging:** a dim overlay focuses attention; the panel rises.
  - **Timing:** 200ms fade, 300ms rise.
  - **Appeal:** clear heading, single focal action.

## 4. Navigation

- **Purpose:** orient the user.
- **Principles applied:**
  - **Staging:** the logo and primary nav item are the focal points.
  - **Arcs:** dropdown and active states move along a natural arc.

## 5. Page transitions

- **Purpose:** maintain context across views.
- **Principles applied:**
  - **Slow In & Slow Out:** the new page eases in; the old page eases out.
  - **Arcs:** shared elements move along an arc into the new page.
